# Nuxt 4 Audio Management & WaveSurfer System Integration

A full-featured web application built with **Nuxt 4**, **Vuetify 3**, and **WaveSurfer.js**, featuring Google OAuth authentication, an interactive Audio Editor studio, and a synchronized Music Library.

## 🚀 Features

- **Google Authentication**: Secure sign-in using Google Identity Services (GIS) with persistent cookies and session management.
- **Interactive Audio Player**: Real-time waveform visualization powered by WaveSurfer.js with customizable playback speed, volume controls, and preset/uploaded track support.
- **Audio Editor Studio**: Modify track settings and seamlessly save edited audio directly to your repository.
- **Music & Audio Library**: Centralized list of saved tracks supporting instant playback navigation and track management.

## 🛠️ Tech Stack

- **Framework**: Nuxt 4 (Vue 3)
- **UI Library**: Vuetify 3 / Vuetify 4
- **Audio Processing**: WaveSurfer.js
- **State Management**: Vue `useState` & browser storage
